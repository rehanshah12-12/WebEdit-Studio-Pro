WEBEDIT STUDIO PRO - FRONTEND STARTER

Files are under public/ to match the current GitHub repository structure.

IMPORTANT:
- This is a static front-end starter. Login, registration, dashboard, and admin are demo interfaces only.
- Do not enter real passwords or store private/customer information until a secure backend, database, password hashing, sessions, and server-side authorization are configured.
- Contact forms prepare a WhatsApp message; they do not store submissions.
- Replace YOUR-DOMAIN.example in robots.txt and sitemap.xml after the final website domain is known.
- WhatsApp and email details in the files are the ones supplied for this project.

To deploy a static preview, publish the public/ folder as the site root. To run a real database-backed site, add a backend/API and configure hosting for it separately.
